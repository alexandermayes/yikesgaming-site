Trouble?

It disconnects right after connecting

Your game is still loading Valheim Plus from the old modded server, and it drops you because this server doesn't run it. Launch Valheim from Steam instead of the mod manager. If you installed the mods by hand, rename winhttp.dll in your Valheim folder to winhttp.dll.off.

"Incompatible version"

Steam hasn't finished updating your Valheim. Close the game, let the update finish in your Steam Library, and try again.

It times out or can't connect

Make sure the address ends in :2456. Use the Copy button so nothing gets mistyped. If it still fails, post in Discord so someone can check the server.

"Invalid password"

Passwords are case-sensitive. Copy it straight from the pinned message in the guild Discord.
