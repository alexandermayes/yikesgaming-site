  1. 1

    Install the mods

    Pick one of three ways, about two minutes

    Close Valheim first, then pick whichever way you like. All three install the same three mods: BepInEx, Valheim Plus and Runic Character Vault.

    Paste one command

    Fastest

    Press the Windows key, type powershell, press Enter, then paste the install command from the card above and press Enter.

    Read the installer first

    Use a mod manager

    No PowerShell

    In r2modman or Thunderstore Mod Manager, pick Valheim, then Profiles, Import / Update, From code, and paste this code. Start the game with Start modded each time you play here.

    01a10413-e3eb-f0f6-0785-ab4286387bf8

    Drag and drop

    Manual

    In Steam, right-click Valheim, choose Manage then Browse local files, and extract the zip there so winhttp.dll sits next to valheim.exe.

    Download the zip

    If something goes wrong here

    Windows blocked writing to the Valheim folder (message in game)

    Some PCs protect the Steam folder. Press the Windows key, type powershell, right-click it, choose Run as administrator, and paste the install command again.

    Can I play on Xbox or Game Pass?

    No. Mods only work on the Steam PC version, and this server needs Valheim Plus.

    I want to play unmodded or on other servers

    Run irm https://yikesgaming.com/uninstall | iex in PowerShell. It switches the mods off without deleting anything. Run the install command again to come back.

  2. 2

    Open Valheim and create a new character

    A fresh character, just for Yikesheim
    Start GamethenStart

    Launch it from Steam like normal. Yikesheim only accepts brand-new characters, so make one just for this server. Your other characters stay exactly as they are for your own worlds.

    If something goes wrong here

    Yikesheim needs a brand-new character (message in game)

    You picked a character that has already played somewhere else. Go back, create a new character, and join with that one. Existing characters can't be brought over. That's the point: everyone starts on equal footing. Your old character isn't changed.

    You already have a character on Yikesheim (message in game)

    Each Steam account gets one character on this server. Select the character named in the message and join with it.

  3. 3

    Join by address

    Join Game, then Join IP
    Join GamethenJoin IPthenConnect

    Paste this into the box and click Connect.

    valheim.yikesgaming.com

    If something goes wrong here

    It can't find the server

    Check the spelling: valheim.yikesgaming.com. If the name still doesn't work, use the server's IP instead: 149.28.193.152:2456. It's the same server.

    It disconnects right after connecting

    Your Valheim Plus is missing or a different version from the server's. Close Valheim and run the install command again. It always installs the exact versions the server uses.

    Incompatible version (message in game)

    Steam hasn't finished updating your Valheim, or Valheim just got a patch. After a patch, Valheim Plus can take a few days to catch up. The host will post in Discord when the server and installer are updated.

  4. 4

    Enter the password

    It's pinned in #valheim on Discord

    It's pinned in #valheim on Discord. Next time, Yikesheim is waiting in the Recent tab, so it's one click plus the password. The server keeps your Yikesheim character safe: when you quit, wait for Saved under the minimap first.

    If something goes wrong here

    Invalid password (message in game)

    Passwords are case-sensitive. Copy it straight from the pinned message in #valheim.
